# 📘 Assignment: Python Functions and File Handling

## 🎯 Objective

Practice writing reusable Python functions and reading data from files. You will build a small program that reads student scores, calculates summaries, and prints clear results using functions.

## 📝 Tasks

### 🛠️ Read and Clean Data from a File

#### Description
Create a function that opens a text file and reads each line, removing extra whitespace and ignoring empty entries.

#### Requirements
Completed program should:

- Open a file using Python's file handling features
- Read each line from the file safely
- Remove extra spaces or blank lines
- Return a list of cleaned values for further processing

### 🛠️ Write Reusable Functions for Calculations

#### Description
Define helper functions that perform simple calculations on the data, such as finding the highest score or counting passing students.

#### Requirements
Completed program should:

- Create at least two functions with clear names and specific jobs
- Use parameters and return values instead of writing repeated logic inline
- Calculate values such as average, highest score, or number of passing grades
- Keep the functions easy to understand and reuse

### 🛠️ Build a Program Summary

#### Description
Use your functions together to produce a final report from the file data.

#### Requirements
Completed program should:

- Call the file-reading function and store the results
- Convert file values to numbers when needed
- Print a friendly summary with totals and key metrics
- Show output such as the highest score, average score, and count of passing grades

### 🛠️ Handle Errors Gracefully

#### Description
Make the program more robust by handling common problems such as a missing file or invalid data.

#### Requirements
Completed program should:

- Catch file-related errors using exception handling
- Handle invalid numeric input without crashing the program
- Display a clear error message when something goes wrong
- Keep the program user-friendly and understandable
